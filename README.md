**VisionIQ** is an innovative smart glasses system designed to provide intelligent, hands-free assistance for students, travelers, and everyday users.

**Key Features:**
- 🌍 Real-time translation and live captions
- 🎓 AI lecture recording, summarization and tutoring
- 👁️ Visual AI assistant for objects, equations and code
- 🗺️ Smart navigation and contextual information
- 🎤 Voice assistant and hands-free interaction
- 📱 Mobile application integration
- 🧠 Seamless learning continuity between glasses and phone
- ⌚ Head gestures, buttons and optional bracelet controls

**Technologies:** ESP32, IoT, AI, Computer Vision, Mobile Development

**Status:** 🚧 In Development
